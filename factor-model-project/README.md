# ML Factor Synthesis

本项目研究一个明确的问题：在沪深300股票池中，机器学习能否比单因子和传统线性组合更有效地整合
多个价量 Alpha，并在严格样本外、计入成本和换手约束后仍保留稳定的选股能力？

项目不是单纯训练一个回归器。它把因子定义、时点对齐、年度 walk-forward、组合构建、成本、稳健性检验
和结果解释放在同一条可复现研究流程中。

> `outputs/` 中随项目附带的结果来自固定随机种子的合成市场，只用于验证研究流程，不能作为沪深300
> 的实证结论。使用真实数据得出结论前，必须补充点时成分股、历史行业和历史流通市值。
>
> 优化版写入 `outputs_optimized/`，不覆盖原始结果。当前实验使用 BaoStock 真实后复权行情与
> AkShare 当前沪深300名单；因缺少历史成分权限，存在幸存者偏差，不得冒充点时成分回测。

## 研究问题与判据

本项目依次回答五个问题：

1. 单个 Alpha 是否具有稳定的横截面预测能力？
2. 等权或历史 ICIR 线性组合能否降低单因子噪声？
3. XGBoost 能否从 20 个因子的 60 日状态中学到有增量价值的非线性关系？
4. 结果是否依赖行业或市值暴露，而不是纯粹的个股选择？
5. 在年度重训、交易成本、换手约束和区块 Bootstrap 后，结论是否仍然成立？

支持“ML 合成有效”的证据不能只是一条上升净值线。至少应同时看到：

- 样本外月度 IC 均值为正，且不同年份没有持续失效；
- ML 的净收益、Sharpe 或回撤优于预先确定方向的单因子基准；
- 相对等权与 ICIR 组合存在增量，而不是所有组合一起上涨；
- 中性化后主要结论不完全消失；
- Bootstrap 区间没有宽到无法区分正收益与随机波动。

若这些证据互相冲突，项目会保留并展示冲突，不把一次回测包装成确定结论。

## 项目是怎样一步一步完成的

下面不是理想化的框架图，而是 `main.py` 实际执行的研究顺序。每一步都说明输入、处理、输出以及最重要的
时序约束。

### 第 1 步：固定实验配置

在 `config.py` 中统一设置数据范围、随机种子、60 日特征窗口、20 日标签、模型候选参数、手续费、滑点、
换手上限和 Bootstrap 次数。所有模块读取同一份配置，避免下载、训练和回测各自维护一套隐含参数。

本次随项目保存的验收配置为：

```text
数据：12 只固定随机种子的合成股票
日期：2018-01-01 至 2025-12-31
特征：20 个 Alpha x 60 个日频滞后
标签：未来 20 个交易日收益
训练：年度扩展窗 walk-forward
测试：2024-2025，共 276 个有效股票月份
```

完整配置和实际模型后端写入 `outputs/run_metadata.json`，因此任何结果都能追溯到运行条件。

### 第 2 步：获取、校验并缓存数据

`data/downloader.py` 提供两条路径：

- `synthetic`：生成具有市场、行业和个股成分的确定性价量面板，用于离线测试完整流程；
- `akshare`：获取免费 A 股日线，支持用户提供成分股文件。

数据被统一为 `date/symbol/open/high/low/close/volume/vwap/market_cap/industry`。进入因子计算前检查必需列、
日期类型、重复键、数值类型和非正 OHLCV。缓存优先使用 Parquet，缺少 `pyarrow` 时退回压缩 CSV。

这里先做缓存再做研究，是为了把“数据源今天是否可用”与“研究代码是否可复现”分离开。

### 第 3 步：实现并计算 20 个论文 Alpha

先在 `factors/operators.py` 实现论文的基础算子，再在 `factors/alpha_factors.py` 组合为 20 个公式。计算按
股票分组、按时间向后滚动；截面排序按同一天分组。因子值的索引始终是 `(date, symbol)`，避免宽表转换中
股票错位。

输出是一张日频因子面板：每行是一只股票在某个交易日的 20 个原始 Alpha 值。

### 第 4 步：执行可选中性化

根据实验模式生成四个版本：

```text
none       原始因子
industry   行业内去均值
size       对 log(市值) 做每日截面回归
both       行业固定效应 + log(市值) 双中性
```

双中性采用 Frisch-Waugh-Lovell 等价变换：先对因子和市值做行业内去均值，再移除共同市值斜率。测试将
向量化结果和显式 OLS 残差比较，防止为了速度改变统计含义。

### 第 5 步：逐日截面预处理

每个交易日、每个因子独立进行 MAD 去极值和 Z-score。没有跨日期拟合一个全局均值或标准差，因为全局
统计量会把未来市场分布带入过去样本，也会让不同市场波动状态失去可比性。

局部滚动相关在常量窗口可能为空。程序保留这种局部缺失，交给 XGBoost 的缺失分支或后备模型的训练期
中位数处理，而不是删除包含任一缺失值的整个月份。

### 第 6 步：构造月末 1,200 维特征

在每个月最后一个交易日，对每只股票展开 20 个因子的过去 60 日完整路径：

```text
alpha002__lag_00 ... alpha002__lag_59
...
alpha101__lag_00 ... alpha101__lag_59
```

保留完整滞后路径而不只计算均值和标准差，是为了让模型自行识别“近期突变”“持续状态”和“不同滞后共同
作用”等形态。代价是特征更多，因此后续限制参数搜索规模，并用年度验证控制过拟合。

### 第 7 步：生成并对齐前向标签

对同一股票计算 `close(t+20) / close(t) - 1`，再与月末特征按 `(date, symbol)` 对齐。标签只用于模型目标、
IC 和回测，不会进入特征列。数据尾部无法观察到完整 20 日收益的样本保留预测值，但不进入绩效评估。

### 第 8 步：建立年度 walk-forward 样本

每个样本同时保存真实的第 20 个未来交易日日期 `_label_date`。年度 purge 按该日期判断标签在训练时是否已经
实现，不再用普通工作日近似中国交易日历。

每个测试年重新执行一次训练：历史数据扩展为训练集，上一年作为验证集，本年作为纯样本外测试集。在当年
1 月 1 日训练前，额外删除其 20 日标签尚未完全实现的年末样本。

以 2024 年模型为例：

```text
训练：2018-01 至 2022-12
验证：2023-01 至 2023-11
删除：2023-12 尚未在 2024-01-01 前完整实现的标签
测试：2024-01 至 2024-12
```

这一步解决的不是普通的特征未来函数，而是更隐蔽的“标签可得时间”泄漏。

### 第 9 步：年度选参、早停和预测

每年只用当年的训练集拟合候选模型，默认用上一年验证 RMSE 选模型并早停，然后一次性预测测试年。也可以
预先设置 `--model-selection ic`，按验证期平均月度 IC 选择超参数。年度模型分别保存，验证 RMSE、MAE、IC、
测试误差、月度 IC 和 ICIR 写入 `walk_forward_report.csv`。

如果 XGBoost 不可用，程序不会静默伪装成 XGBoost，而是记录 `ridge-fallback`。这保证数据、回测和报告
仍可离线验收，同时把“工程流程成功”和“XGBoost 实证成功”明确分开。

`fallback` 是备用机制名称，不代表当前结果使用了它。原 `outputs/` 的实际模型是
`XGBRegressor`，优化版是 `XGBRanker`；两个 `run_metadata.json` 均明确记录
`model_backend: xgboost` 和 `fallback_used: false`。

### 第 10 步：构造三个非 ML 基准

- 单因子：分别对 20 个因子回测，方向只由 2024 年前的历史 IC 决定；
- 等权：当期 20 个标准化因子直接平均；
- ICIR：每个调仓日只使用当时已经实现的历史 IC 序列更新权重。

主图展示的单因子由测试前 `abs(ICIR)` 预选，而不是从测试结果中挑收益最高者。所有单因子仍完整输出，
方便观察因子合成是否真的优于输入信号。

### 第 11 步：将信号转换为受约束组合

每月按得分排序，目标组合做多前 10%、做空后 10%，多空两侧等权。然后比较旧权重与目标权重：若换手
超过 30%，只完成允许比例的换仓。最后用实际成交权重计算毛收益，并扣除 3 bp 手续费和 10 bp 滑点。

这一步非常重要，因为一个预测准确但需要每月完全翻转的信号，未必能转化为可交易收益。

### 第 12 步：计算预测与组合指标

预测层输出月度 Spearman IC、ICIR、五分层收益和因子相关矩阵；组合层输出年化收益、Sharpe、最大回撤、
胜率、平均换手和总成本。预测层与组合层分开分析，避免仅凭净值倒推模型有效。

### 第 13 步：执行三类稳健性实验

1. 年度稳定性：分开观察 2024、2025 和未来可用年份；
2. 区块 Bootstrap：500 次、3 个月 moving-block 重采样，估计收益和 IR 区间；
3. 中性化实验：四套特征分别重新构造样本、重新训练、重新回测。

中性化不是在原始预测结果上简单做一次回归，而是让整个 ML 训练过程看到不同的信息集合。

### 第 14 步：保存结果并执行测试

所有中间结论以 CSV、PNG、JSON 和年度模型文件落盘。`pytest` 检查时序方向、标签对齐、年度 purge、
中性化 OLS 等价性、单因子选择隔离、成本、换手和 Bootstrap 可复现性。当前共 22 项测试通过。

## 为什么选择这些因子

实现直接对应论文 *101 Formulaic Alphas* 附录，而不是用普通技术指标替换论文 Alpha。选择 20 个只依赖
OHLCV/VWAP 的公式，原因是免费数据容易获得、公式可以完整复现，同时能覆盖不同经济直觉：

| 维度 | Alpha 编号 | 主要信息 |
|---|---|---|
| 价量相关 | #2、#3、#6、#13、#14、#22、#40 | 价格变化与成交活跃度的时序关系 |
| 反转与动量 | #7、#9、#10、#12、#38、#43 | 短期价格延续、反转及成交量条件 |
| 截面价格结构 | #4、#5、#11、#18、#33 | 开收盘、VWAP、波动与截面排序 |
| 日内结构 | #41、#101 | 高低价区间和开收盘相对位置 |

论文算子统一实现在 `factors/operators.py`，包括截面 `rank`、`delay`、`delta`、滚动相关、协方差和
`ts_rank`。所有滚动窗口均为向后窗口，不读取当前行之后的数据。

这些因子并不保证在月频预测中有效。选择它们的目的，是为“异质弱信号能否被稳健合成”提供一个透明、
可审计的特征池，而不是事后筛选历史表现最好的 20 个公式。

## 为什么预测未来 20 日收益

标签定义为：

```text
target(t) = close(t + 20) / close(t) - 1
```

20 个交易日大致对应一个自然月，与月末调仓频率匹配。相比预测下一日收益，它降低了微观结构噪声和日频
交易成本的主导程度；相比季度标签，它又保留了足够的训练截面和策略响应速度。

需要明确：原论文 Alpha 多为更短持有期。本项目不是复现论文收益，而是把论文公式当作日频状态变量，研究
它们对未来约一个月横截面收益的联合预测能力。

## 特征与截面处理

每个月最后一个交易日，为每只股票保留过去 60 个交易日的 20 个 Alpha：

```text
20 factors x 60 lags = 1,200 features per stock-month
```

每天的每个因子独立执行：

1. MAD 去极值：截断在 `median +/- 3 x 1.4826 x MAD`；
2. 截面 Z-score：消除量纲并保留当日相对排序；
3. 可选中性化：`none`、`industry`、`size`、`both`。

中性化只使用同一天的横截面。行业模式等价于行业内去均值；市值模式回归 `log(market_cap)`；双中性模式
使用行业固定效应去均值后再移除市值斜率，与“截距 + 行业哑变量 + log 市值”的 OLS 残差代数等价。

## 为什么使用 XGBoost

等权和 ICIR 都是线性组合，无法自然表达以下关系：

- 某个反转信号只在成交量异常时有效；
- 波动率处于特定区间后，动量信号方向或强度发生变化；
- 同一因子的近期值、20 日前值和 60 日状态共同决定预测。

XGBoost 能拟合阈值、非线性交互和缺失分支，对不同量纲和相关特征也较稳健。项目通过上一年度验证集进行
早停和小型参数搜索，目标函数为 `reg:squarederror`，记录 RMSE、MAE 和月度 Spearman IC。

如果运行环境没有 XGBoost，流程会明确记录 `ridge-fallback` 并用确定性线性模型完成工程验收。后备结果
不能被称为 XGBoost 实验；实际后端写入 `run_metadata.json` 和 `walk_forward_report.csv`。

## 年度 Walk-Forward

默认采用扩展窗口，每年 1 月重新训练一次：

| 测试年 | 训练集 | 验证集 | 预测集 |
|---|---|---|---|
| 2024 | 2018-2022 | 2023 | 2024 |
| 2025 | 2018-2023 | 2024 | 2025 |
| 2026 | 2018-2024 | 2025 | 2026-07 |

在每个训练时点，程序会额外 purge 最近 20 个交易日：只有完整前向收益在当年 1 月 1 日前已经实现的样本，
才能进入训练或验证。每年都会重新选参、早停、保存模型，并输出：

- 当年训练/验证起止日期和样本数；
- 验证 RMSE、MAE；
- 测试 RMSE、MAE、月度 IC 和 ICIR；
- 各年度净收益、Sharpe 和最大回撤；
- 各年度特征重要性及跨年平均重要性。

`--static-model` 可运行旧式 2018-2022 单次训练，用作方法对照，不应替代默认 walk-forward 结论。

## 四类策略对比

测试期统一按月调仓，做多得分最高 10%，做空最低 10%。比较对象为：

1. **单因子**：20 个 Alpha 分别回测。方向和展示用“最佳单因子”仅由 2024 年前历史 ICIR确定；
2. **等权组合**：20 个当期标准化因子等权平均；
3. **ICIR 组合**：每月仅用当时已经实现的历史标签计算扩展 ICIR 权重；
4. **ML 合成**：年度 walk-forward 模型的样本外预测值。

全部 20 个单因子结果保存在 `single_factor_summary.csv`。主绩效图中的单因子不是测试期事后赢家，从而避免
“在测试集挑一个最好看的因子再比较”的选择偏差。

## 成本与换手

默认假设：

- 手续费：3 bp；
- 滑点：10 bp；
- 单次组合换手率上限：30%；
- 换手定义：`0.5 * sum(abs(w_new - w_old))`；
- 成本按实际交易名义本金 `sum(abs(delta_weight))` 收取。

若目标组合要求的换手超过 30%，实际权重沿“旧组合到目标组合”的方向只移动允许的比例。这相当于延迟换仓，
不会通过简单删掉成本或事后缩放收益来伪造可交易性。

## Bootstrap 稳健性

项目对每个主策略执行 500 次、3 个月区块的循环 moving-block bootstrap。与逐月独立抽样相比，区块抽样
保留一部分短期收益自相关，更适合月频策略。

每次抽样保存：

- 年化收益；
- 信息比率；
- 最大回撤。

报告给出年化收益和 IR 的 95% 分位数区间，并保存完整分布。区间跨过零意味着当前样本不足以证明策略稳定，
即使点估计为正也应谨慎解释。

## 中性化实验

运行 `--neutralization-experiment` 会对四个特征版本分别重建样本并重新执行年度 walk-forward：

```text
raw -> industry-neutral -> size-neutral -> industry-and-size-neutral
```

比较年化收益、Sharpe、最大回撤、换手率和逐年收益。解释原则如下：

- 原始有效、中性后失效：预测可能主要来自行业轮动或市值风格；
- 中性后仍有效：更支持个股层面的增量选股信息；
- 中性后改善：原始风格暴露可能是噪声或风险来源；
- 各年份结论反复：信号具有明显市场状态依赖，需要更长样本或分阶段模型。

## 本项目当前结果与解读

### 先说明结果适用范围

下面数字来自 `outputs/` 中保存的验收运行：12 只合成股票、2018-2025、2024-2025 样本外。实际训练环境为
XGBoost 3.3.0 和 scikit-learn 1.9.0，`run_metadata.json` 与两个年度报告均确认后端为 `xgboost`。

这次运行可以证明 XGBoost、walk-forward、基准、成本、Bootstrap 和中性化流程能够正确联动，但合成数据
仍然不能回答“XGBoost 在真实沪深300是否有效”。

### 总体策略表现

| 策略 | 年化收益 | Sharpe | 最大回撤 | 平均换手 | 年化收益 Bootstrap 95% 区间 |
|---|---:|---:|---:|---:|---:|
| XGBoost | -13.46% | -1.27 | -26.24% | 30.00% | [-22.57%, -4.30%] |
| 等权组合 | -3.83% | -0.33 | -11.16% | 30.00% | [-14.37%, 7.76%] |
| ICIR 组合 | 11.12% | 1.43 | -7.45% | 26.09% | [-1.84%, 27.07%] |
| 预选单因子 Alpha#5 | -6.55% | -0.55 | -21.15% | 30.00% | [-20.39%, 6.60%] |

第一层结论是：XGBoost 没有战胜任何组合基准，表现也弱于预选单因子。ICIR 的收益、Sharpe 和换手均为
四者最佳，说明在这个小型合成样本上，历史线性权重比高维非线性合成更有效。

第二层结论是：XGBoost 的 Bootstrap 年化收益区间整体低于零，表明负表现不是单一月份偶然造成的。其余
三个策略的区间仍跨过零，包括点估计最好的 ICIR。因此当前结果既不支持 XGBoost 有效，也不能证明 ICIR
存在稳定正收益。

### 不同年份是否稳定

| 策略 | 2024 净收益 | 2025 净收益 |
|---|---:|---:|
| XGBoost | -10.75% | -15.07% |
| 等权组合 | -3.76% | -3.59% |
| ICIR 组合 | 9.62% | 11.66% |
| Alpha#5 | -1.25% | -11.06% |

XGBoost 两年均为负，2025 年进一步恶化；ICIR 两年均为正，在当前验收样本中明显更稳。walk-forward 的
价值正在这里：它表明问题不是某一次年度重训偶然失败，而是当前特征、样本规模和模型组合没有形成稳定
非线性增量。

年度平均月度 IC 接近零：2024 年为 0.0012，2025 年为 0.0077。预测几乎没有稳定的全截面单调关系，而
尾部多空组合持续为负，说明模型在排序两端的错误更具破坏性。必须同时查看 IC、分层曲线和多空尾部收益，
不能因为 IC 略大于零就宣称预测有效。

### 因子层结果

按全部月份统计，Alpha#3 的平均 IC 约为 0.203，但 IC 标准差约为 0.589，稳定性有限。XGBoost 跨年度
聚合的重要性前五为 Alpha#4、#7、#5、#38、#9，主要覆盖截面价格位置、成交量条件和短期反转。

这里的重要性来自两个年度 XGBoost 模型的 `feature_importances_`，再按 Alpha 聚合 60 个滞后。它只能说明
模型在哪些变量上进行了较多分裂或贡献分配，不能证明这些变量具有稳定收益，更不能解释为因果关系。当前
重要性较高但组合为负，恰好说明“模型使用了某个因子”不等于“模型正确使用了这个因子”。

### 中性化结果

| 特征版本 | 年化收益 | Sharpe | 最大回撤 |
|---|---:|---:|---:|
| 原始 | -13.46% | -1.27 | -26.24% |
| 行业中性 | -7.91% | -0.88 | -22.08% |
| 市值中性 | -9.61% | -0.49 | -26.58% |
| 行业+市值中性 | 9.64% | 0.58 | -21.82% |

双中性版本由负转正，而只做行业或只做市值中性仍为负。这表明行业与市值暴露可能以交互方式干扰模型，
同时移除后模型更容易利用剩余个股信息。不过双中性最大回撤仍达到 -21.82%，且当前流程没有为四个中性化
版本分别计算 Bootstrap 区间，因此只能把它看作进一步研究线索，不能据此选择测试期表现最好的版本。

由于验收股票池只有 12 只、分成 8 个合成行业，行业内截面非常小，行业中性结果本身也较脆弱。正式沪深300
实验拥有更大的行业内样本后，才适合判断这一结论是否延续。

### 当前研究结论

这次运行可以支持三点：

1. 工程上，XGBoost 年度重训、无泄漏基准、成本、Bootstrap 和四种中性化均已完整运行；
2. 研究上，ICIR 明显优于 XGBoost，证明复杂模型不会自动优于透明的线性组合；
3. 诊断上，原始 XGBoost 两年均负且 Bootstrap 区间低于零，当前非线性模型存在稳定的样本外失效；
4. 中性化上，双中性版本转正提供了风格交互线索，但还需要独立统计检验和更大股票池确认。

下一步真正有价值的实验不是依据这两个测试年继续调参，而是在点时沪深300成分股、历史行业和历史市值
数据上运行同一套流程，并预先固定参数空间。随后可增加低维滚动摘要特征作为对照，检验 1,200 维完整滞后
是否导致高方差，以及为四种中性化模式分别计算 Bootstrap 区间。

### 为什么当前 XGBoost 效果差

为了避免只凭感觉归因，项目额外保存 `model_diagnostics.json`，并对特征维度、标签形式和股票数量做了受控
诊断。当前负表现主要由以下因素共同造成。

#### 1. 特征数大于训练样本数

2024 年模型使用 720 个训练股票月份，却输入 1,200 个特征，特征/样本比为 1.67；2025 年仍为 1.39。
每个基础 Alpha 又有 60 个高度相关的相邻滞后，树模型很容易在训练期找到偶然阈值，却难以跨年复现。

把输入降到 20 个当前值后，诊断期年化约为 3.99%、平均 IC 为 0.089；保留 6 个代表滞后的 120 维版本，
年化约为 5.30%、平均 IC 为 0.128。结果说明降维显著改善稳定性。

这些实验是在看到正式测试结果后进行的，属于 post-hoc diagnosis，不能拿来替换正式结果或宣称改进策略
有效。它们只能形成下一次预注册实验的假设。

#### 2. 回归目标与交易目标不完全一致

XGBoost 用原始未来 20 日收益的 MSE 训练，但组合真正关心的是同一个月内股票排序。原始收益包含所有股票
共同的市场和行业波动；模型降低绝对收益误差，不等于提高 Spearman IC 或尾部多空价差。

80 维摘要特征配合“每月前向收益去截面均值”后，诊断期年化约为 7.01%、平均 IC 为 0.102；但在完整
1,200 维特征上只改变标签仍然为负。这说明目标对齐有帮助，却无法抵消高维噪声。

#### 3. 合成数据的可预测结构没有直接按 Alpha101 构造

合成生成器只加入了很弱的日收益反转与非线性滞后项，并没有让未来 20 日收益直接由所选 20 个 Alpha 决定。
市场、8 个行业和个股噪声占比更高。因此“流程中存在可学习非线性”不代表“这些 Alpha 在月频截面上有
足够信噪比”。这更接近一次压力测试，而不是为 XGBoost 量身定做的演示数据。

#### 4. 模型早停很早，验证集已在提示无信号

正式运行中，2024/2025 年模型最佳迭代分别只有 20 和 2。扩大到 50 只股票后，2024 年最佳迭代仍为 0，
2025 年为 72；平均测试 IC 仍只有 0.009。样本扩大把年化从 -13.46% 改善到约 -2.14%，但没有产生稳定
预测力，说明小样本是放大器而非唯一原因。

#### 5. 预测横截面被严重压缩

测试期模型月内预测标准差约为 0.00394，真实收益月内标准差约为 0.05924，预测离散度只有目标的 6.65%。
模型对大多数股票给出相近预测，Top/Bottom 10% 实际是在非常微弱的分数差异上做尾部选择，排序容易被噪声
翻转。

#### 6. RMSE 和 IC 都没有显示样本外技能

测试 RMSE 为 0.07398，永远预测 0 的 RMSE 为 0.07251，相对技能为 -2.03%；平均月度 IC 只有 0.0043，
IC 标准差约 0.231。也就是说模型不仅没有稳定排序能力，点预测甚至略差于零预测。

#### 7. 成本不是主要原因

在 30% 换手约束下，去掉手续费与滑点后年化仍约为 -12.64%，加入成本后为 -13.46%，年化成本拖累约
0.82%。完全放开换手且不计成本仍约为 -5.27%。因此不能通过调低成本假设解释或修复模型失效。

将分数反向后测试收益为正是测试期事后观察；由于整体 IC 接近零，这更可能是尾部抽样偶然，不可以据此把
信号乘以 -1。正式策略方向必须由训练或验证数据预先决定。

#### 8. 下一步应如何验证

下一轮实验应在新的未使用测试期或真实点时数据上预先固定以下对照：

1. 20 维当前值、120 维稀疏滞后、80 维滚动摘要和 1,200 维完整路径；
2. 原始收益与截面去均值收益标签；
3. RMSE 选参与验证 IC 选参；
4. XGBoost 与正则化线性模型；
5. 每个设定的年度 IC、Bootstrap 和中性化稳定性。

只有在新的 holdout 上复现，才能把本次诊断假设升级为正式研究结论。

## 优化版：从高维回归到真实截面排序

优化版保留原项目的 Alpha101、年度 walk-forward、成本、换手和 Bootstrap 框架，但把数据、
特征筛选、标签与训练目标一起改成了面向真实沪深300截面选股的版本。原结果位于 `outputs/`，
优化版独立写入 `outputs_optimized/`。

### 修改 1：训练期 ICIR 筛选和滞后去冗余

新增 `model/feature_selection.py`。每个测试年都只用当年 walk-forward 训练集计算月度 Spearman IC：

1. 以因子 `lag_00` 的月度 IC 计算年化 ICIR，仅保留 `ICIR > 0.5` 的因子；
2. 对合格因子的60个滞后按 `abs(mean IC)` 排序；
3. 每个因子最多保留 3 个滞后，逐轮分配直到达到20–30维；
4. 如果严格阈值下不足20维，程序会告警并保留实际合格维度，不会回填 `ICIR <= 0.5` 的因子凑数。

筛选使用的因子 ICIR、各滞后 IC 和最终特征分别写入 `training_factor_icir.csv` 和
`training_lag_ic.csv`。这个过程在每个年度重新执行，不读取2024–2026测试标签。

### 修改 2：标准化、预测分布和 PCA 候选

原有20个因子仍然在每个交易日的横截面内执行 MAD 去极值和 Z-score，不使用跨日或全样本
均值。优化版额外输出 `feature_scaling_diagnostics.csv`，逐年检查训练集与验证集的特征均值、
标准差和缺失率。

`prediction_distribution.csv` 同时保存训练集和验证集的预测均值、标准差、5%/50%/95%
分位数、目标标准差和预测/目标离散度比。这比只看一个总体的6.65%更容易判断信号是在训练期
就被压缩，还是到验证期才失效。

模型会在验证集同时比较原精选特征和10个 PCA 主成分。PCA 的中位数填补、均值、标准差和主成分
均只在训练集拟合；最终是否使用 PCA 由预先指定的验证 IC 规则决定。

### 修改 3：横截面目标与 XGBoost 排序

样本现在同时保留两个字段：

- `target_return`：真实未来20个交易日收益，只用于 IC 解读和组合回测；
- `target`：当月横截面百分位排名减0.5，作为模型标签。

这样既不会用排名值冒充真实投资收益，又能让训练目标与截面选股一致。默认 XGBoost 目标改为
`rank:pairwise`，也支持 `rank:ndcg` 和 `reg:squarederror`。每个月是一个独立 ranking group，
调参同时记录 RMSE、MAE 和月度 IC，默认按验证 IC 选择候选，完整表位于
`model_candidate_metrics.csv`。

### 修改 4：真实行情数据与可审计降级

代码支持 Tushare、AkShare 和 BaoStock。实际运行时，Tushare 账号没有 `index_weight` 与
`index_member_all` 权限，`adj_factor` 也被限制为每分钟1次；AkShare 的东方财富历史行情端点则连续
被代理中断。项目因此使用了可完整运行的降级路径：

- AkShare 提供当前300只沪深300代码；
- BaoStock 提供2016年末至2026-07-31的真实后复权 OHLCV；
- VWAP 在复权量纲下用 `(high + low + close) / 3` 近似；
- 流通市值和点时行业缺失，因此本次不做市值/行业中性化。

下载按股票写入 `data/cache/baostock_symbols/`，完整面板缓存约26.6MB。
`run_metadata.json` 明确记录 `point_in_time_membership=false`、市值/行业覆盖为0，所以下面的数字是
“真实价量+当前成分股”实验，而不是完全点时的沪深300指数回放。

### 优化版实际结果

样本为2018–2022初始训练、2023初始验证、2024–2026年度 walk-forward 测试，共30个可评估月份和
8,932个股票月份。2026只覆盖截至数据结束日已完整实现20日标签的部分，不是完整自然年。

| 策略 | 年化净收益 | Sharpe | 最大回撤 | Bootstrap年化区间 |
|---|---:|---:|---:|---:|
| XGBoost排序 | 2.58% | 0.28 | -15.26% | [-6.84%, 14.29%] |
| 等权因子 | -7.76% | -0.45 | -31.87% | [-21.49%, 10.65%] |
| ICIR组合 | -6.76% | -0.51 | -27.03% | [-18.80%, 8.83%] |
| 预选 alpha041 | 0.46% | 0.11 | -11.82% | [-7.78%, 8.43%] |

XGBoost逐年净收益为2024年2.90%、2025年3.97%和2026部分期间-0.38%。它在点估计上优于三个
基准，但 Bootstrap 区间宽且跨零，所以只能说“弱的正向证据”，不能宣称策略已稳定有效。

特征数从1,200降为2024年21维、2025年20维、2026年22维，完成20–30维目标；合格因子分别为
7、10、11个。2024年验证选中10维 PCA，2025和2026保留原精选特征。

但信号强度问题没有解决：全测试期预测/目标月度离散度比只有4.68%，低于原诊断的6.65%；月度
IC均值仅0.0130，正 IC 月份占46.67%，零预测基准上的 RMSE skill 为-0.26%。2024、2025、2026测试 IC
分别为-0.0135、0.0176、0.0570，稳定性仍然不足。

原 `outputs/` 合成数据中 XGBoost 年化-13.46%、Sharpe -1.27、IC 0.0043；优化版变为年化2.58%、
Sharpe 0.28、IC 0.0130。然而数据源、股票数和标签都同时改变，两者不是严格的单变量因果对照；
可以确认的是维度大幅下降、收益点估计改善，但预测分布仍过度收缩，统计证据仍弱。

## 本项目的主要决策以及原因

### 决策 1：研究沪深300，而不是全 A 股

**选择**：把目标股票池限定为沪深300成分股。

**原因**：大盘股流动性更好，停牌、极端点差和无法成交对回测的影响相对较小；股票数量足以做横截面排序，
又不会让免费数据下载和本地计算成本过高。这也使项目重点落在因子合成，而不是小微盘流动性溢价。

**没有选择的方案**：全 A 股能提供更大截面，但会显著增加 ST、上市不足、涨跌停、退市、微盘容量和数据
质量处理。若这些约束没有同步实现，更大的股票池反而更容易产生虚高结果。

**代价**：沪深300存在成分股变更，若只使用当前名单会产生幸存者偏差。因此真实研究必须提供点时成分股；
代码在使用当前名单时会明确警告。

### 决策 2：选择 20 个透明的 Alpha101 公式，而不是海量技术指标

**选择**：从论文中选择 20 个仅依赖 OHLCV/VWAP、逻辑覆盖不同维度的 Alpha。

**原因**：公式有公开出处、可以逐项审计，而且免费行情足以计算。20 个因子能展示异质信号合成，又不会在
有限年份上形成“几百个候选中挑赢家”的严重数据挖掘。

**没有选择的方案**：直接生成几百个均线、RSI 和参数组合实现更简单，但难以说明选择依据，也容易把参数
搜索误当成研究深度。基本面因子具有经济价值，但需要点时财报和公告日处理，不适合作为本项目第一版输入。

**代价**：所选公式偏价量，无法代表完整的多因子体系，也可能共享相似市场暴露，所以额外输出相关矩阵和
中性化结果。

### 决策 3：月末调仓并预测未来 20 个交易日

**选择**：月末产生信号，以未来 20 日累计收益为标签。

**原因**：标签期限和调仓频率大致一致；相比日频标签，噪声和成本占比更低；相比季度标签，样本数量和模型
更新速度更合理。对于求职项目，月频也更容易完整解释组合形成、换手和成本。

**没有选择的方案**：1 日标签更接近部分原论文 Alpha 的持有期，但需要更细的成交时点和冲击成本模型；60 日
或季度标签会减少独立时间样本并降低策略响应速度。

**代价**：相邻月末之间约 20 个交易日，标签可能轻微重叠，因此普通 IID 统计假设偏乐观。本项目用区块
Bootstrap 保留部分序列依赖，但不能完全消除这一限制。

### 决策 4：保留 60 日完整滞后，而不是只做滚动摘要

**选择**：每个因子展开 lag 0 至 lag 59，共 1,200 个特征。

**原因**：均值、标准差等摘要会预先规定模型只能看到某些形态；完整路径允许模型区分近期反转、持续趋势、
衰减速度和不同滞后的交互。

**没有选择的方案**：只保留当前值计算更快，但无法体现因子状态；滚动均值/波动/斜率维度更低，适合数据量
更小时作为稳健性对照；LSTM 等序列模型能够直接读序列，但样本规模不足且解释成本更高。

**代价**：特征数相对样本数较高，容易过拟合。因此采用小参数网格、浅树、列采样、早停、年度验证和跨年
重要性比较，而不做大规模超参数优化。

### 决策 5：逐日 MAD 去极值和 Z-score

**选择**：在每个交易日横截面独立处理异常值与量纲。

**原因**：金融因子常有厚尾，均值和标准差会被极端点影响；MAD 更稳健。截面 Z-score 与最终横截面选股目标
一致，也避免价格、相关系数和成交量类公式的数值尺度直接影响组合。

**没有选择的方案**：3 Sigma 对近似正态数据简单，但在厚尾因子上不稳；全样本标准化会读取未来分布；
分位数 rank 很稳健，但会丢失截面距离信息。

**代价**：MAD 为零或截面过小时可能产生缺失，因此程序保留局部缺失并显式处理，而不是静默填零。

### 决策 6：原版使用 XGBRegressor，优化版改用 XGBRanker

**原版选择**：使用带早停的 `XGBRegressor`，以未来20日原始收益为标签，目标函数为
`reg:squarederror`。候选参数默认按上一年度验证集 RMSE 选择。这一设置用于检验非线性模型能否改善
绝对收益预测，但与实际交易更关心的月度横截面排序并不完全一致。

**优化版选择**：改用 `XGBRanker`，以“当月未来20日收益百分位排名减0.5”为标签，默认目标函数为
`rank:pairwise`，并将每个月作为独立 ranking group。候选模型同时记录验证 RMSE、MAE 和月度
Spearman IC，默认优先选择验证 IC 更高的组合，使训练目标、调参标准和多空选股目标更一致。

**原因**：树模型能捕捉阈值与因子交互，天然处理非线性，对特征缩放不敏感，并能提供特征重要性和 SHAP。
它比深度网络更适合当前中等规模表格数据，也比线性回归更能回答“非线性合成是否带来增量”。

**没有选择的方案**：线性模型是必要基准但不是研究主角；随机森林通常缺少 boosting 对弱信号的逐步拟合；
神经网络需要更多数据、正则化和稳定性分析，且解释难度更高。

**为什么修改**：原版用 MSE 优化绝对收益误差，即使 RMSE 下降，也不一定能正确排列同月股票。优化版采用
pairwise 排序损失，直接惩罚股票相对次序错误，更贴近做多高分组、做空低分组的交易方式。

**代价**：排序目标仍可能拟合噪声，较高的验证 IC 也不保证组合收益稳定；特征重要性同样不代表因果。
因此两个版本都必须和等权、ICIR、单因子比较，并通过年度 walk-forward、Bootstrap 和中性化实验判断
增量。依赖不可用时可以使用后备模型完成工程检查，但报告必须明确实际后端，不能把 fallback 混称为
XGBoost。本项目保存的原版和优化版正式结果均未触发 fallback。

### 决策 7：使用扩展窗年度 walk-forward，而不是随机交叉验证

**选择**：每年重新训练，历史窗口不断扩展，上一年负责验证。

**原因**：投资策略部署只能用过去预测未来；年度重训既能吸收新市场数据，也能保留较大的训练样本。逐年
报告可以直接暴露市场阶段变化。

**没有选择的方案**：随机 K-fold 会让未来样本进入过去训练；一次固定训练无法观察模型更新后的稳定性；
固定长度滚动窗更强调新数据，但会丢弃早期样本，当前时间长度下方差更高。

**代价**：可用于独立比较的测试年份较少，所以结果不能仅靠年度均值证明，需要配合 Bootstrap 和更长真实
数据。每年训练前还必须 purge 末尾未实现标签。

### 决策 8：设置单因子、等权和 ICIR 三类基准

**选择**：不只比较“有模型”和“没模型”，而是建立由弱到强的基准阶梯。

**原因**：单因子回答合成是否有价值；等权回答简单分散是否足够；ICIR 回答历史线性权重是否已经捕捉主要
信息。只有 ML 超过这些基准，才能把增量合理归因于非线性合成。

**没有选择的方案**：只和指数收益比较无法区分市场 Beta 与选股能力；在测试期选择最优单因子会产生明显
数据窥探。

**代价**：ICIR 本身可能不稳定，因此权重只用已实现的扩展历史，并同时报告换手与 Bootstrap 区间。

### 决策 9：构建多空尾部组合

**选择**：做多前 10%、做空后 10%，两侧等权。

**原因**：多空收益更直接衡量横截面排序能力，弱化整体市场涨跌；10% 尾部让组合聚焦最强信号，同时保留
一定分散度。

**没有选择的方案**：纯多头更贴近部分真实账户，但会混入市场 Beta；连续分数权重利用全部股票，却对得分
尺度和异常预测更敏感；Top 5 等固定数量在股票池变化时分散度不稳定。

**代价**：真实 A 股做空受券源约束，所以该组合首先是因子研究组合，而不是可直接下单的产品。落地时可改成
多头超额或股指期货对冲版本。

### 决策 10：显式加入成本和 30% 换手上限

**选择**：手续费 3 bp、滑点 10 bp，并沿旧权重到目标权重裁剪换手。

**原因**：价量信号容易产生高换手，不计成本会系统高估表现。裁剪实际权重比简单在报表中把换手截成 30%
更严谨，因为后续收益由真正可达到的权重计算。

**没有选择的方案**：固定扣一个月度费用无法反映信号变化；完全拒绝超限调仓会产生不连续行为；按比例移动
更接近实际执行中的延迟换仓。

**代价**：固定 13 bp 没有反映股票流动性和交易规模。真实研究应把个股成交额、参与率、涨跌停和冲击函数
加入成本模型。

### 决策 11：采用 moving-block Bootstrap

**选择**：500 次循环区块重采样，默认区块长度 3 个月。

**原因**：月度收益并不一定独立，连续月份可能处于同一市场状态。区块抽样比逐月 IID Bootstrap 更能保留
短期自相关，并能直接输出收益、IR 和回撤的经验分布。

**没有选择的方案**：正态近似置信区间对偏态、厚尾和小样本较脆弱；按年度重采样只有两个验收年份，信息
太少；更复杂的 stationary bootstrap 可以作为后续稳健性检查。

**代价**：3 个月区块是研究选择，不是理论最优值。正式报告应比较 2、3、6 个月区块，观察结论敏感性。

### 决策 12：把中性化作为重新训练实验

**选择**：原始、行业、市值、双中性分别走完整特征、训练和回测流程。

**原因**：如果只对最终预测做中性化，模型训练时仍然利用了风格信息，无法回答“去除这些暴露后模型还能
学到什么”。从输入端重新训练才能比较不同信息集合。

**没有选择的方案**：只报告模型预测和行业/市值的相关系数成本更低，但不能反映非线性交互中的风格依赖。

**代价**：计算量约增加到四倍；真实数据还要求点时行业与市值，否则中性化本身也会泄漏或失真。

### 决策 13：保留离线合成数据，但不把它当研究证据

**选择**：默认提供确定性 synthetic 模式，同时支持 AkShare。

**原因**：网络、接口和成分股数据不应阻止用户验证因子计算、时序切分、模型、回测和图表是否工作。固定
随机种子也便于测试结果可复现。

**没有选择的方案**：强制每次联网会让项目难以复现；把下载好的真实大文件直接放进仓库会增加体积和授权
问题。

**代价**：合成数据的收益和显著性没有投资含义。因此 README、元数据和日志都会标记数据源，真实结论必须
重新运行点时数据。

## 防止未来数据泄漏

代码中显式约束：

- 不随机打乱股票月份样本；
- 滚动因子和 60 日特征只向后取值；
- 去极值、标准化和中性化仅在同日横截面完成；
- 标签列从不进入模型特征列表；
- 年度训练前 purge 尚未实现的 20 日标签；
- ICIR 权重只读取当前调仓日前已实现的历史 IC；
- 单因子方向和选择不读取测试期标签；
- 测试集末尾尚未实现的标签不会被当作零收益。

相应行为由测试锁定，而不是仅靠注释约定。

## 快速运行

安装依赖：

```powershell
python -m pip install -r requirements.txt
```

离线、固定随机种子的完整年度 walk-forward：

```powershell
python main.py --source synthetic
```

快速验收：

```powershell
python main.py --source synthetic --symbols 20 --end-date 2025-12-31
```

四种中性化完整实验：

```powershell
python main.py --source synthetic --neutralization-experiment
```

在新的、未使用 holdout 上预先按验证 IC 选参：

```powershell
python main.py --source synthetic --model-selection ic
```

当前随项目保存的正式结果仍使用 spec 约定的 RMSE 选择；不能在看过现有测试结果后切换规则并覆盖结论。

当前可复现的优化版真实行情：

```powershell
python main.py --source baostock --output-dir outputs_optimized
```

默认时间分割为2018–2022训练、2023验证、2024–2026测试；每个测试年执行扩展窗重训练。
首次下载按股票缓存，仅在确实需要废弃缓存时使用 `--refresh`。

Tushare 路径仍然保留，但需要 `index_weight`、`adj_factor`、`daily_basic` 和
`index_member_all` 的足够权限：

```powershell
$env:TUSHARE_TOKEN="你的 Token"
python main.py --source tushare --output-dir outputs_optimized
```

切换为截面去均值回归或 NDCG 排序：

```powershell
python main.py --source baostock --target-mode demean --objective reg:squarederror
python main.py --source baostock --target-mode rank --objective rank:ndcg
```

安装 SHAP 后可以额外输出最新年度模型解释图：

```powershell
python main.py --shap
```

## 如何解释实验结果

面试或研究报告中建议按以下顺序表达，而不是从最高收益数字开始：

1. 先说明因子覆盖的经济直觉，以及为什么不按测试期表现筛因子；
2. 展示月度 IC 和年度 walk-forward 稳定性，确认预测层是否有效；
3. 比较单因子、等权、ICIR 和 ML，判断非线性合成是否真正提供增量；
4. 加入成本和换手，说明预测优势能否转换为组合收益；
5. 查看中性化实验，判断收益来源是个股信息还是风格暴露；
6. 最后用 Bootstrap 区间讨论统计不确定性和样本长度限制。

一个可信的结论可以是“ML 点估计更高，但 Bootstrap 区间跨零且 2025 年 IC 下降，因此目前只支持存在增量
信号的弱证据”，而不是简单宣称模型战胜市场。能清楚说明证据强弱，本身就是这份项目的研究价值。

## 已知限制

- 合成数据只能验证代码与实验逻辑；
- 当前成分股列表会造成幸存者偏差；
- 免费数据的历史行业、市值和 VWAP 精度有限；
- 20 日标签在月末间可能轻微重叠，Bootstrap 只能部分缓解依赖性；
- 固定手续费和滑点没有表达个股流动性、冲击成本与策略容量；
- 参数搜索空间刻意较小，避免在有限年份上做大规模数据挖掘；
- SHAP 是模型解释工具，不等于经济因果解释。

# Spec: ff-three-factor-model

## 1. Project Goals

本项目旨在构建一个基于 Fama-French 三因子模型的多因子选股回测系统，在原有双均线回测框架基础上升级为融合市场因子、规模因子（SMB）和价值因子（HML）的量化选股策略。

项目目标包括：

- 下载沪深 300 成分股的日线历史数据，覆盖至少 50 只股票。
- 计算每只股票的市场因子暴露、规模因子暴露和价值因子暴露。
- 基于三因子综合评分进行月度调仓，选出综合得分最高的前 10% 股票进行买入。
- 评估策略表现，并输出累计收益率、年化收益率、最大回撤和夏普比率。
- 生成策略净值曲线图，并与沪深 300 基准进行对比展示。

---

## 2. Functional Requirements

### 2.1 数据获取
- 使用 `yfinance` 或 `akshare` 下载股票日线数据。
- 需支持沪深 300 成分股数据获取，至少包含 50 只股票。
- 数据需要按日期升序排列，确保后续回测逻辑正确。

### 2.2 因子计算
- 计算每只股票的市值，定义为收盘价 × 流通股数。
- 计算每只股票的账面市值比，定义为每股净资产 / 股价。
- 对所有因子暴露进行标准化处理（Z-score），以保证不同因子尺度可比。

### 2.3 因子分组与构建
- 每月末根据市值排序，将股票分为小盘股组和大盘股组，用于构建 SMB 因子。
- 每月末根据账面市值比排序，将股票分为价值股组和成长股组，用于构建 HML 因子。
- 计算每只股票的市场 Beta，用于构建市场因子暴露。

### 2.4 选股逻辑
- 采用三因子综合得分进行选股：
  - 三因子综合得分 = 0.3 × SMB 暴露 + 0.3 × HML 暴露 + 0.4 × 市场 Beta
- 选股信号必须基于前一个月末的数据生成，避免未来函数。
- 每月初调仓，买入综合得分最高的前 10% 股票。

### 2.5 交易与费用
- 交易成本中包含万分之三手续费和千分之一滑点。
- 回测结果应充分考虑交易成本对策略收益的影响。

### 2.6 绩效分析
- 输出策略的累计收益率、年化收益率、最大回撤、夏普比率。
- 输出年度绩效报告，包含 Alpha、Beta、夏普比率、最大回撤。
- 生成策略净值曲线与沪深 300 基准净值曲线对比图。
- 生成月度收益率分布图。

### 2.7 可配置性
- 代码中应包含参数调整说明，例如调仓频率、股票数量、因子权重等，便于后续优化与实验。

## 3. Technical Constraints

- 编程语言：`Python 3.x`
- 依赖库：
  - `yfinance` 或 `akshare`
  - `pandas`
  - `numpy`
  - `matplotlib`
  - `statsmodels`
- 数据处理要求：
  - 所有时间序列数据必须按日期升序排列。
  - 信号生成必须基于前一个月末可用数据，避免使用未来信息。
- 因子计算要求：
  - 所有因子计算必须进行标准化（Z-score）处理。
- 结果输出要求：
  - 回测结果需在终端中输出关键绩效指标。
  - 生成图片文件并保存至当前工作目录。
- 代码结构要求：
  - 代码应具备清晰的模块化结构，便于后续扩展和维护。
  - 参数配置应通过明确注释说明，方便使用者调整策略参数。

# 因子择时复现与组合方法比较

| 项目信息 | 当前口径 |
| --- | --- |
| 研究标的 | 沪深300当前成分股的因子多空收益 |
| 有效样本 | 2021-01-04 至 2026-07-28，1,348 个交易日 |
| 默认调仓 | 周频，t 日信号、t+1 日执行 |
| 基准成本 | 手续费 10 bps + 滑点 5 bps / L1 换手 |
| 对比方法 | 等权、择时得分、Top-K、分位排名、逆波动 |
| 最终判断 | 存在状态依赖，但无显著且稳定的样本外超额 |
| README 更新 | 2026-08-01 |

本项目复现《广发金工：因子择时——在波动市场中寻找稳健 Alpha》的核心思路，并重点回答一个可检验的问题：

> 基于因子择时得分生成的动态权重，在统一数据、执行时点、交易成本和换手约束后，是否真的优于简单等权？

当前答案是：**尚不能证明择时组合显著优于等权**。全样本中择时得分组合的扣费后年化收益略高，但 Sharpe 低于等权，收益差的 bootstrap 置信区间跨过 0；严格 walk-forward 样本外结果也没有跑赢等权。逆波动风险加权在当前样本中表现更稳，但同样尚未达到统计显著。

这是一套研究框架和近似复现，不是可直接交易的策略。当前数据使用“现时沪深300成分股”回看历史，存在幸存者偏差；价值、质量和市值中的部分字段也是代理变量。

## 研究问题、假设与结论

**研究问题：** 在完全相同的因子收益、执行时点、成本和换手约束下，择时得分加权是否在收益、风险及统计意义上优于简单等权？

**可检验假设：**

- H1：择时得分组合扣除成本后的年化收益和 Sharpe 高于等权。
- H2：择时的相对优势在牛市、熊市、高波动和低波动环境中不同。
- H3：当成本上升或调仓更频繁时，高换手择时策略的优势会衰减。
- H4：如果动态加权真有稳定信息，其超额应在 bootstrap 和 walk-forward 中仍然成立。

**方法：** 比较等权、择时得分、Top-K、分位排名和逆波动五种组合；检查全样本绩效、牛熊与波动状态、成本/调仓频率敏感性、配对收益差、移动区块 bootstrap 和 walk-forward 样本外表现。

**关键发现：**

- 择时得分在牛市中最有效：年化收益 25.64%、Sharpe 1.66，明显高于等权的 6.10% 和 1.07。
- 择时并不擅长防守：熊市中等权亏损最小；高波动期等权 Sharpe 最高。
- 震荡期逆波动 Sharpe 最高；低波动期分位排名表现最好，说明动态权重具有明显状态依赖。
- 周频总成本提高到 20 bps 后，择时得分相对等权的年化超额转为 -0.35%；逆波动仍有约 0.09% 正超额，成本稳健性更好。
- 所有动态策略相对等权的 bootstrap 置信区间均跨过 0；walk-forward 中择时也未跑赢等权，因此不能宣称获得稳定显著 Alpha。

**研究结论：** 择时得分适合被理解为一种偏进攻、依赖牛市和低波动环境的配置方法，而不是等权组合的普遍替代品。当前更稳健的候选是逆波动组合，但其收益改善很小，仍需要更长、无幸存者偏差的样本验证。

对四个假设的判断是：H1 不成立（收益略高，但 Sharpe 更低且不显著）；H2 成立（状态依赖明显）；H3 成立（高换手方法对成本敏感）；H4 不成立（显著性和样本外证据均不支持）。

## 本轮优化

项目原来已有等权基准、手续费、周期调仓和 walk-forward。本轮补齐并统一了以下内容：

- 所有组合严格使用同一份 `factor_returns.csv`，避免输入差异污染比较。
- 增加 5 种组合：等权、择时得分、Top-K、分位排名、逆波动风险加权。
- 统一采用 t 日收盘生成目标权重、t+1 日执行，防止当日收益泄漏。
- 对所有动态组合使用相同的手续费、滑点、调仓频率和单次换手上限。
- 同时输出毛收益、扣费后净收益、权重、换手率和累计成本。
- 增加牛市/震荡/熊市及高波动/低波动分层。
- 增加 4 档成本 × 3 种调仓频率的敏感性测试。
- 增加配对收益差检验和 20 日移动区块 bootstrap 置信区间。
- 修复 walk-forward 信号与执行的双重滞后，使时序统一。
- 增加回测时点、等权换手和组合权重约束的单元测试。

## 数据处理与因子构造

默认股票池为沪深300当前成分股，数据由 AKShare 获取并缓存在 `data/akshare/`。日频输入包括复权 OHLC、成交量、成交额和可用的市值代理。

### 数据口径

- 行情频率：日频。
- 复权方式：AKShare 前复权（`qfq`）。
- 成分股口径：拉取时点的沪深300成分股，不是逐日历史成分。
- 停牌/无效价格：剔除收盘价或成交量非正的观测。
- 市值：优先使用 `close × outstanding_share`；缺失时用 60 日成交额中位数作尺寸代理。
- 市场代理：样本股日收益等权平均，不是正式的沪深300全收益指数。

`data/` 保存可重用的原始缓存，`outputs/` 只保存由这些输入推导出的结果，避免重复存储大型行情文件。

### 因子定义

当前因子如下：

| 因子 | 简化定义 | 方向解释 |
| --- | --- | --- |
| `momentum_20` | $P_t/P_{t-20}-1$ | 过去 20 日涨幅越高，暴露越高 |
| `reversal_5` | $-(P_t/P_{t-5}-1)$ | 过去 5 日越弱，反转暴露越高 |
| `volatility_20` | $-\sigma(r_{t-19:t})$ | 波动越低，暴露越高 |
| `size` | $-\log(MarketCap)$ | 规模越小，暴露越高 |
| `liquidity` | $-\log(Amount)$ | 成交额越低，暴露越高；更接近“低流动性” |
| `value_proxy` | 有 BM 时用 BM，否则用 $-(P_t/P_{t-252}-1)$ | 代理变量，不等同于真实价值因子 |
| `quality_proxy` | 有 ROE 时用 ROE，否则用 60 日平均收益 | 代理变量，不等同于真实质量因子 |

每个交易日对所有股票的因子暴露做 1%/99% 缩尾，再做横截面 z-score。因子 $j$ 的次日多空收益为：

$$
f_{j,t+1}=\frac{1}{|L_{j,t}|}\sum_{i\in L_{j,t}}r_{i,t+1}
-\frac{1}{|S_{j,t}|}\sum_{i\in S_{j,t}}r_{i,t+1}
$$

其中 $L_{j,t}$ 是因子暴露最高的 20% 股票，$S_{j,t}$ 是最低的 20%。这一定义意味着：`factor_returns.csv` 里的每一列本身已是一个多空组合的收益，后续的“因子权重”是对这些多空收益再做一层配置。

### 择时信号与综合得分

择时分数由六类信号加权：

- 因子收益动量：35%
- 因子收益反转：15%
- 因子收益波动惩罚：20%
- 市场趋势：15%
- 市场波动状态：10%
- 因子相关性分散度：5%

对因子 $j$ 在 t 日的综合得分，可写为：

$$
Score_{j,t}=0.35MOM_{j,t}+0.15REV_{j,t}+0.20VOL_{j,t}
+0.15TREND_t+0.10MKT\_VOL_t+0.05DISP_t
$$

- $MOM$：因子收益 20 日均值的时序 z-score。
- $REV$：因子收益 5 日累计值的负 z-score。
- $VOL$：因子收益 20 日波动率的负 z-score。
- $TREND$：市场代理收益 60 日均值的 z-score。
- $MKT\_VOL$：市场代理 20 日波动率的负 z-score。
- $DISP$：因子间 60 日平均相关性的负 z-score；相关性越低，分散得分越高。

各分量的时序 z-score 默认使用 252 日滚动均值和标准差，最少 20 个观测。综合得分被截断到 `[-3, 3]`。滚动统计只使用截至 t 日已知的数据；目标权重在下一个交易日生效。

需要注意，市场趋势、市场波动和分散度在同一日对所有因子加上相同分量。它们不会直接改变因子排名，但会通过“只保留正分”的非线性映射影响有效因子数量和权重集中度。

## 公平比较实验

### 对比策略

| 策略 | 目标权重 |
| --- | --- |
| `equal_weight` | 7 个因子恒定等权 |
| `timing_score` | 只保留正择时分数，初次归一化后做 35% 软截断，再归一化 |
| `top_k` | 选择得分最高的 3 个因子并等权 |
| `rank_weight` | 保留排名位于上半区的因子，按百分位排名加权 |
| `risk_weight` | 按过去 60 日因子波动率的倒数加权 |

所有策略均为只多因子组合，权重非负且合计为 1。这里的“只多”指对多空因子收益序列分配非负权重，不代表底层股票组合没有空头。

五种权重方法的具体映射如下：

1. **等权**

   $$w_{j,t}=1/N$$

   不根据信号做任何变化，是最小假设、最难被过拟合的基准。

2. **择时得分加权**

   $$\tilde w_{j,t}=\max(Score_{j,t},0),\qquad
   w_{j,t}=\frac{\tilde w_{j,t}}{\sum_k\tilde w_{k,t}}$$

   初次归一化后，单因子权重先被截断到 35%，再对全部权重归一化。如果所有得分都非正，退回等权。

   **实现口径提醒：** 35% 是归一化之前的软截断，不是最终严格上限。当正分因子很少时，第二次归一化会让最终权重重新超过 35%。当前输出中择时组合最大实际单因子权重为 75%，1,348 个交易日中有 661 日超过 35%。本 README 按现有实验如实报告；如果要研究严格上限，应将权重投影到带上界的单纯形后重跑全部结果。

3. **Top-K 等权**

   对得分排名最高的 $K=3$ 个因子分配 $1/K$，其余为 0。这是对“信号只有排序信息、没有精确幅度信息”的检验。

4. **分位排名加权**

   保留当日得分百分位排名在 50% 以上的因子，按百分位数归一化。它介于 Top-K 的离散筛选和得分加权的连续映射之间。

5. **逆波动风险加权**

   $$w_{j,t}=\frac{1/\sigma_{j,t}^{(60)}}{\sum_k1/\sigma_{k,t}^{(60)}}$$

   不使用择时得分，只根据过去 60 日因子波动率分配风险。它是一个重要的“简单但不弱”基准。

### 回测时序与防泄漏

对每个调仓周期，回测器按以下顺序处理：

1. 在 t 日收盘后，用截至 t 日的因子收益和市场收益计算目标权重。
2. 每个调仓周期选取该周期最后一个真实交易日的目标。
3. 目标权重整体 `shift(1)`，从 t+1 日开始赚取因子收益。
4. 如目标权重与当前权重的 L1 差超过 0.50，按比例缩小调整量。
5. 使用实际权重计算当日毛收益，再减去当日组合层交易成本。

这里的一日滞后非常关键。如果用 t 日收益生成权重，又让该权重赚取 t 日收益，就会产生前视偏差。

### 交易与成本假设

默认参数在 `src/factor_timing/config.py`：

| 参数 | 默认值 |
| --- | ---: |
| 调仓频率 | 每周五 `W-FRI`，节假日取该周期最后一个实际交易日 |
| 手续费 | 0.10% / 单位 L1 权重变化 |
| 滑点 | 0.05% / 单位 L1 权重变化 |
| 单次调仓换手上限 | 0.50（L1） |
| 执行滞后 | 1 个交易日 |

组合层换手定义为：

```text
turnover_t = Σ |w_t - w_(t-1)|
cost_t = turnover_t × (transaction_cost + slippage)
net_return_t = Σ w_(t,i) × factor_return_(t,i) - cost_t
```

例如从因子 A 转出 20% 并转入因子 B 20%，L1 换手为 40%。如果研究习惯采用单边换手，应将这里的 L1 换手除以 2 后再比较。

等权目标始终不变，因此其“因子组合层”换手为 0。**这不表示构造底层因子多空组合没有换手和成本**；当前 `factor_returns.csv` 尚未扣除底层股票交易成本。因为所有组合使用同一批因子收益，这部分被视为共同输入，但不同因子本身换手不同，未来应进一步在股票层建模。

### 如何修改参数

核心默认值位于 `src/factor_timing/config.py` 的 `ResearchConfig`：

```python
ResearchConfig(
    rebalance_freq="W-FRI",        # D / W-FRI / ME
    long_quantile=0.20,             # 多头分位
    short_quantile=0.20,            # 空头分位
    transaction_cost=0.0010,        # 10 bps / L1 换手
    slippage=0.0005,                # 5 bps / L1 换手
    max_rebalance_turnover=0.50,    # 单次 L1 换手上限
    max_factor_weight=0.35,           # 归一化前软截断，非严格上限
    random_seed=42,
)
```

`run_akshare.py` 中对起止日期有运行时覆盖。如果要进行正式对比，建议每次只修改一类参数，并将参数与输出目录一起归档。

### 评价指标

`comparison_metrics.csv` 包括：

- 年化净收益与年化毛收益
- 相对等权的年化净收益差
- 年化波动率、Sharpe、最大回撤和日胜率
- 日均换手、年化换手和累计组合层交易成本

Sharpe 默认无风险利率为 0、按 252 个交易日年化。年化收益使用几何复利；显著性表中的平均收益差则是日均差乘以 252，因此两者数值不必完全相同。

主要指标的计算口径为：

$$
AnnualReturn=\left(\prod_{t=1}^{T}(1+r_t)\right)^{252/T}-1
$$

$$
AnnualVolatility=\sigma(r_t)\sqrt{252},\qquad
Sharpe=\frac{\bar r}{\sigma(r_t)}\sqrt{252}
$$

$$
MaxDrawdown=\min_t\left(\frac{NAV_t}{\max_{s\le t}NAV_s}-1\right)
$$

解读时不应只挑选年化收益最高的方法。一个更有说服力的组合应同时满足：净收益高于基准、Sharpe 没有恶化、回撤可控、换手与成本可接受，并且优势在样本外和统计检验中没有消失。

## 当前结果

当前缓存样本为 2021-01-04 至 2026-07-28，共 1,348 个因子收益观测。基准参数下：

| 策略 | 年化净收益 | Sharpe | 最大回撤 | 年化 L1 换手 | 相对等权年化收益 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 等权 | 2.39% | 0.37 | -21.60% | 0.00 | 0.00% |
| 择时得分 | 3.05% | 0.30 | -19.88% | 19.56 | 0.66% |
| Top-K | 0.93% | 0.14 | -25.70% | 15.70 | -1.46% |
| 分位排名 | 2.59% | 0.28 | -25.07% | 19.42 | 0.20% |
| 逆波动 | 2.58% | 0.41 | -18.92% | 2.02 | 0.19% |

这些结果说明：

1. 择时得分组合的全样本净收益略高、回撤略小，但承担了更高波动和很高的组合层换手，Sharpe 反而低于等权。
2. Top-K 和分位排名没有显示出稳定优势，复杂权重并不会自动带来更好结果。
3. 逆波动策略的收益改善很小，但 Sharpe 和回撤更好，且换手显著低于择时策略；风险控制可能比追逐得分更有价值。
4. 这些只是当前带幸存者偏差样本上的结果，不能直接外推到真实投资表现。

### 毛收益、净收益与成本拖累

| 策略 | 年化毛收益 | 年化净收益 | 累计组合层成本 | 年化 L1 换手 |
| --- | ---: | ---: | ---: | ---: |
| 等权 | 2.39% | 2.39% | 0.00% | 0.00 |
| 择时得分 | 6.12% | 3.05% | 15.70% | 19.56 |
| Top-K | 3.34% | 0.93% | 12.59% | 15.70 |
| 分位排名 | 5.63% | 2.59% | 15.58% | 19.42 |
| 逆波动 | 2.90% | 2.58% | 1.62% | 2.02 |

“累计成本”是每日成本收益项的简单加总，不是毛净值终值之差。这张表直观显示：择时得分的原始选择能力并非完全没有，但大部分毛收益优势被高换手吞噬。逆波动的亮点则是用很小的换手获得了更好的风险调整表现。

### 显著性检验

对每个动态策略计算“策略日净收益 - 等权日净收益”，并进行：

- 配对 t 统计量；表中 p 值使用大样本正态近似。
- 20 日移动区块 bootstrap，2,000 次重采样、95% 置信区间、随机种子 42。

当前择时得分相对等权的年化日均收益差约 1.21%，bootstrap 95% 区间约为 `[-8.77%, 12.44%]`，明显跨过 0；其配对检验近似 p 值约 0.82。其他备选策略的置信区间也都跨过 0。

| 策略 vs 等权 | 年化日均收益差 | 配对 t 统计量 | 近似 p 值 | Bootstrap 95% 区间 | 是否显著 |
| --- | ---: | ---: | ---: | ---: | --- |
| 择时得分 | 1.21% | 0.23 | 0.82 | [-8.77%, 12.44%] | 否 |
| Top-K | -1.01% | -0.22 | 0.82 | [-9.29%, 9.32%] | 否 |
| 分位排名 | 0.64% | 0.14 | 0.89 | [-8.23%, 10.70%] | 否 |
| 逆波动 | 0.17% | 0.18 | 0.86 | [-1.84%, 2.66%] | 否 |

移动区块 bootstrap 而不是逐日独立重采样，是为了在一定程度上保留日收益的短期自相关和波动聚集。这里的配对 t 检验 p 值使用大样本正态近似，主要用于辅助诊断；研究结论更依赖区块 bootstrap 与样本外结果。

因此本项目当前能支持的表述是：

> 全样本存在局部改善，但没有统计证据证明扣除组合层成本后，择时加权显著优于等权。

不能表述为“择时方法已经被证明有效”。

## 稳健性检验

### 市场状态

`comparison_regime_metrics.csv` 同时提供两组分层：

- 趋势状态：市场近 60 日累计收益的下 1/3、中间 1/3、上 1/3，标记为熊市、震荡、牛市。
- 波动状态：市场近 20 日波动率低于或高于全样本中位数，标记为低波动和高波动。

状态计算先对市场数据滞后一日，避免用当日市场收益给当日策略贴标签。该分层是描述性分析，分位点仍由全样本确定，不应当作实时可交易信号。

分状态年化收益 / Sharpe 如下：

| 市场状态 | 等权 | 择时得分 | Top-K | 分位排名 | 逆波动 | 状态内最高 Sharpe |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 熊市 | -2.70% / -0.28 | -11.62% / -0.89 | -15.50% / -1.34 | -14.00% / -1.14 | -4.30% / -0.52 | 等权 |
| 震荡 | 3.90% / 0.60 | -1.30% / -0.06 | 2.30% / 0.28 | 2.80% / 0.32 | 4.90% / 0.75 | 逆波动 |
| 牛市 | 6.10% / 1.07 | 25.64% / 1.66 | 19.00% / 1.41 | 22.20% / 1.64 | 7.40% / 1.28 | 择时得分 |
| 高波动 | 4.30% / 0.55 | 0.90% / 0.14 | -1.30% / -0.03 | -2.80% / -0.14 | 3.70% / 0.52 | 等权 |
| 低波动 | 0.60% / 0.13 | 5.20% / 0.51 | 3.20% / 0.38 | 8.20% / 0.86 | 1.50% / 0.28 | 分位排名 |

这张表是项目最有信息量的结果之一：

- 择时得分不是防守型策略，而是在牛市中集中到强因子的进攻型策略。
- 在熊市和高波动环境中，频繁改变因子暴露没有带来更好的风险补偿，等权反而更稳。
- 逆波动在震荡市场最有效，说明当方向信号较弱时，直接管理风险可能优于预测因子强弱。
- 低波动期间动态权重整体更好，但这是描述性结果，不是事前可直接使用的切换规则。

### 成本与调仓频率

`comparison_sensitivity.csv` 覆盖：

- 总成本率：0、5、10、20 bps / 单位 L1 换手
- 调仓频率：每日、每周、每月
- 5 种组合方法

当前敏感性结果中，择时得分在 12 个成本/频率组合里有 8 个取得正超额，但最差到最好超额约为 -9.14% 至 3.73%，对设定并不稳定。逆波动在 12 个组合中均为微弱正超额，范围约 0.09% 至 1.06%，但改善幅度很小，仍需更长样本和样本外检验。

以周频为例，成本对年化超额的影响是：

| 总成本 / L1 换手 | 择时得分 | Top-K | 分位排名 | 逆波动 |
| --- | ---: | ---: | ---: | ---: |
| 0 bps | 3.73% | 0.94% | 3.24% | 0.50% |
| 5 bps | 2.69% | 0.13% | 2.21% | 0.38% |
| 10 bps | 1.66% | -0.68% | 1.19% | 0.28% |
| 20 bps | -0.35% | -2.27% | -0.82% | 0.09% |

成本为 0 并不是现实假设，它的作用是拆分“信号的毛收益”和“为获得该收益付出的交易代价”。当成本从 0 增加到 20 bps 时，择时得分的超额下降约 4.08 个百分点，而逆波动只下降约 0.41 个百分点。

下一阶段值得补充的参数敏感性包括：因子形成窗口、择时信号窗口、Top-K 的 K 值、单因子权重上限和换手上限。当前版本没有把所有窗口做网格搜索，是为了避免在同一小样本上进一步扩大数据挖掘偏差。

### Walk-forward 样本外验证

现有验证使用：

- 504 日训练窗口
- 126 日验证窗口
- 126 日测试窗口
- 126 日滚动步长

每一折只按验证期 Sharpe 从 4 个预先定义的择时信号配方中选一个，然后仅拼接测试期收益。所有权重仍为 t 日生成、t+1 日执行，并采用相同手续费、滑点和换手上限。

四个候选配方的权重在研究前固定：

| 候选 | 因子动量 | 因子反转 | 波动惩罚 | 市场趋势 | 市场波动 | 分散度 | 软权重截断 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `balanced` | 35% | 15% | 20% | 15% | 10% | 5% | 35% |
| `momentum_defensive` | 45% | 5% | 25% | 10% | 10% | 5% | 30% |
| `market_state` | 20% | 10% | 15% | 30% | 20% | 5% | 35% |
| `low_turnover` | 30% | 5% | 30% | 15% | 15% | 5% | 25% |

名称 `low_turnover` 表示设计意图，并不是一个强制换手最小化器；它主要通过更低的权重软截断和更高的波动惩罚权重实现更防守的配置。

当前拼接样本外结果：

| 组合 | 年化收益 | Sharpe | 最大回撤 |
| --- | ---: | ---: | ---: |
| walk-forward 择时 | -0.94% | 约 0.00 | -21.96% |
| 等权因子 | 1.13% | 0.22 | -9.48% |

样本外结果不支持择时优于等权。由于当前历史长度只够形成少量折，结论的不确定性仍很大；增加真实历史成分数据和更长样本比继续调参更重要。

当前共形成 5 个滚动折，每折的候选选择如下：

| 折 | 验证期选中候选 | 测试开始 | 测试结束 |
| ---: | --- | --- | --- |
| 1 | `momentum_defensive` | 2023-08-09 | 2024-02-19 |
| 2 | `balanced` | 2024-02-20 | 2024-08-21 |
| 3 | `low_turnover` | 2024-08-22 | 2025-03-05 |
| 4 | `balanced` | 2025-03-06 | 2025-09-04 |
| 5 | `momentum_defensive` | 2025-09-05 | 2026-03-19 |

每折中，训练窗口用于记录候选表现，验证窗口用于选择候选，测试窗口只负责生成最终样本外收益。各测试窗口按时间顺序拼接，不使用未来测试结果反向修改当期选择。

## 已知局限与研究优先级

当前最重要的局限按优先级排列：

1. **历史成分偏差**：使用当前沪深300成分股回测历史，具有明显幸存者偏差。
2. **底层成本缺失**：只计算因子组合层换手，未计算各多空因子的股票层换手、冲击成本和融券成本。
3. **代理因子较弱**：`value_proxy`、`quality_proxy` 和部分市值字段不是真实基本面因子。
4. **市场基准近似**：`market_proxy` 是当前成分股近似等权收益，不是正式沪深300全收益指数。
5. **样本较短**：有效区间约 5.5 年，市场状态和 walk-forward 折数有限。
6. **统计检验有限**：同时比较多个策略会产生多重检验问题；当前没有做 Reality Check、SPA 或 FDR 校正。
7. **因子收益可交易性**：日频分位数组合默认能以理想价格形成，未完整处理涨跌停、停牌和容量限制。
8. **因子权重上限为软约束**：现有实现的 35% 截断发生在最终归一化之前，实际权重可以超过 35%；这可能放大择时组合的集中度和波动。

建议下一步优先获取历史成分股、真实流通市值和财务因子，并在股票层构造含成本的因子收益；之后再扩展信号窗口和模型参数。否则继续优化择时权重，很容易只是放大样本内拟合。

## 常见问题

### 为什么择时年化收益更高，却不能说它更好？

因为它的年化波动约 12.83%，明显高于等权的 7.13%，导致 Sharpe 反而更低。同时 0.66% 的几何年化收益差很小，bootstrap 区间又跨过 0，无法排除随机波动。

### 为什么等权换手是 0？

这里统计的是上层“因子之间”的权重变化。等权目标恒定，所以上层换手为 0；但底层因子多空组合每日仍可能换股。这是当前成本模型的重要局限。

### 牛市中择时表现很好，能否直接做市场状态切换？

不能直接这样推断。当前状态分位阈值由全样本计算，主要用于事后描述。要将它变为可交易规则，必须使用当时可见数据决定阈值，并另做样本外测试。

### 为什么不继续搜索更多参数直到显著？

因为在约 5.5 年的同一样本上反复尝试窗口、阈值和策略，会引入严重的多重检验和数据挖掘偏差。当前更有价值的改进是增加无偏数据和股票层成本，而不是继续寻找最优参数。

## 如何陈述这个项目

一个准确、有说服力的简历或面试表述是：

> 我构建了一个沪深300因子择时研究框架，将择时得分与等权、Top-K、分位排名和逆波动置于统一的次日执行、成本和换手约束下比较。结果显示择时在牛市有明显的描述性优势，但高换手使其对成本敏感，且 bootstrap 与 walk-forward 均不支持其稳定显著优于等权。逆波动的风险调整收益和成本稳健性更好，但收益改善幅度仍小。

应避免声称“复现了研报全部因子”、“策略已获得稳定 Alpha”或“已可实盘”。更专业的表达是：本项目复现了研报的核心研究问题和可获取信号子集，并对“复杂加权是否优于简单基准”做了含否定结果的完整验证。

# 组合方法公平对比实验

所有策略使用完全相同的因子收益、样本区间、调仓日、次日执行规则和成本模型。

- 调仓频率：`W-FRI`
- 手续费：0.1000% / 单位 L1 换手
- 滑点：0.0500% / 单位 L1 换手
- 单次调仓 L1 换手上限：0.5
- Top-K：3
- 统计检验：20 日移动区块 bootstrap，95% 置信区间，固定随机种子

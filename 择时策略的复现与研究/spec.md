# 01 研报复现 Spec

## 项目目标

复现《广发金工：因子择时——在波动市场中寻找稳健 Alpha》研究的核心思路，验证因子择时信号在波动市场中的有效性，并搭建可部分复刻的因子择时策略框架。

## 关键问题

- 数据获取与处理：获取基础市场数据和因子数据，并完成对齐、清洗和复权。
- 因子计算：尽力准备可获得的因子，目标复刻代表性子集；若无法全部获取，则优先选用常见 Alpha 因子和 Barra 风格因子进行替代。
- 综合打分与权重选择：构建可复刻的择时信号集合，优先实现可获取的信号子集，并设计信号融合、因子打分与权重调整策略。
- 回测与绩效评估：评估择时策略的年化收益、超额收益、夏普比、最大回撤等指标，并与未择时组合对比。

## 复现步骤

1. 数据准备
   - 采集日频历史价格：开盘、收盘、最高、最低、成交量、市值等。
- 采集因子值：优先获取可用因子，目标复刻代表性子集；如果无法全部获取，可用常见 Alpha 因子和 Barra 风格因子近似替代。
   - 数据清洗：对齐交易日、处理缺失值、剔除停牌、执行复权。

2. 构建择时信号
   - 选取并实现可获取的代表性择时信号，优先复刻可获得的信号子集。
   - 典型信号类型：因子表现趋势、波动率、Alpha 变化、行业择时、宏观周期指标等。
   - 输出每个已实现信号的历史时间序列和择时方向。

## 可复刻因子清单（建议）

- Alpha 因子子集：
  - 深度学习因子：`fimage`、`DL_1`、`agru_dailyquote`
  - Level-2 高频因子：`bigbuy_bigsell`、`integrated_bigsmall_longshort`、`transaction_order_ratio_oa1`
  - 分钟频因子：`real_skewlarge`、`real_var`、`Amihud_illiq`

- 另外可补充的因子：
  - 常见 Alpha 因子：动量、价值、成长、质量、波动率、规模等，用于对比和替代不足的数据项。
  - Barra 近似风格因子：市值、动量、价值、波动率、盈利能力等。

## 可复刻择时信号清单（建议）

- 动量类：
  - RSRS 择时信号（趋势强度判断）。
  - 低延迟趋势线（LLT）信号。
  - 因子收益动量：短期因子表现与历史均值对比。

- 波动率类：
  - 历史波动率与波动率动能。
  - 指数高阶矩择时（高阶矩变化判断风险偏好）。
  - 因子收益/组合收益的波动率上升或下降信号。

- 反转类：
  - 因子收益超买/超卖反转指标。
  - 短期回撤后反弹信号。
  - 因子收益下穿历史均值后的回归信号。

- 特征差类：
  - 因子间相关性变化。
  - 因子间协同度或分歧度。
  - 行业/风格特征差异信号。

- 额外可采纳的公开实现：
  - RSRS、LLT、指数高阶矩择时等。
  - 这些信号可作为“动量/波动率/反转/特征差”四类的代表性实现。

## 可复刻方式说明

- 先从上述因子和信号清单中选取 5-10 个可用项，形成最小可复刻集。
- 通过子集复刻验证“因子择时思想”，而不是追求完全复制 77+92 的规模。
- 若数据资源允许，再逐步扩展到更多因子和信号。

3. 因子择时逻辑
   - 将择时信号映射到因子表现上，验证信号与因子收益的相关性。
   - 实现“多信号-单因子”择时逻辑。
   - 实现“多信号-多因子”择时逻辑。
   - 设计信号融合方法：分数加权、排序筛选、阈值开关等。

4. 因子组合构建
   - 建立基准组合：常规模型为等权因子组合或未择时组合。
   - 根据择时结果动态调整因子权重或选取因子组合。
   - 确定调仓期、约束条件、交易成本假设。

5. 回测与评估
   - 回测择时策略的历史表现。
   - 计算指标：年化收益、超额年化收益、夏普比、最大回撤、择时胜率等。
   - 与未择时等权组合、指数增强基准比较。

6. 结果分析
   - 总结有效信号与因子组合。
   - 检验波动市场下的稳健性。
   - 输出结论与应用建议。

## 交付内容

- `data/`：原始数据与清洗后数据。
- `signals/`：择时信号生成代码与历史信号结果。
- `factors/`：因子计算代码与因子数据。
- `backtest/`：回测逻辑与绩效分析代码。
- `report/`：复现结果、图表和结论分析文档。
